# Table: `requests`

The central operational table tracking all slaughter intake bookings, animal descriptions, attached documentation, and lifecycle states.

---

## Schema Definition

| Column Name | Data Type | Nullable | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `id` | `BIGINT` | NO | `GENERATED BY DEFAULT` | Primary key identifier |
| `user_id` | `UUID` | YES | `NULL` | Foreign key referencing `profiles.id` |
| `customer_name` | `TEXT` | NO | — | Full name of meat owner/dealer |
| `contact_number` | `TEXT` | YES | `NULL` | Mobile contact number |
| `address` | `TEXT` | YES | `NULL` | Source farm / residence address |
| `request_type` | `TEXT` | NO | `'barangay'` | Intake category: `'barangay'` or `'market'` |
| `livestock_type` | `TEXT` | NO | `'hog'` | Animal category: `'hog'`, `'cattle'`, `'carabao'`, `'goat'` |
| `animal_count` | `INTEGER` | NO | `1` | Total head count of livestock batch |
| `live_weight` | `NUMERIC(8,2)` | YES | `NULL` | Live animal weight upon arrival (kg) |
| `preferred_date` | `DATE` | NO | `CURRENT_DATE` | Requested slaughter date |
| `status` | `TEXT` | NO | `'pending'` | Current state machine lifecycle status |
| `health_cert_url` | `TEXT` | YES | `NULL` | URL to Veterinary Health Certificate |
| `shipping_permit_url`| `TEXT` | YES | `NULL` | URL to Livestock Shipping Permit |
| `barangay_clearance_url`| `TEXT` | YES | `NULL` | URL to Barangay Origin Clearance |
| `created_at` | `TIMESTAMPTZ` | NO | `NOW()` | Submission timestamp |
| `released_at` | `TIMESTAMPTZ` | YES | `NULL` | Final dispatch / pickup timestamp |

---

## Allowed Status Values (`status`)
1. `pending`: Initial submission, awaiting administrative intake review.
2. `approved`: Intake approved, schedule assigned.
3. `doc_verified`: Physical permits and brand verification confirmed.
4. `anti_mortem_failed`: Rejected during ante-mortem inspection (disease/unfit).
5. `slaughter_started`: Animal in slaughter line (stunning, scalding, evisceration).
6. `post_mortem_failed`: Carcass condemned during post-mortem examination.
7. `releasable`: Post-mortem passed, carcass weight logged, ready for cashiering.
8. `payment_pending`: Customer chose Cash on Pickup, awaiting cashier payment.
9. `paid`: Payment cleared (GCash or Cashier Cash Receipt).
### 10. `completed`: Meat released through gate pass.
### 11. `cancelled`: Cancelled by user or administrative rejection.
